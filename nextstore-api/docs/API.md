# مستندات API

> ⚠️ این فایل **دستی نوشته نمی‌شود**. با فرمان زیر از روی
> خودِ مسیرها و توضیحات کنترلرها ساخته می‌شود:
>
>     php artisan docs:api
>
> پس اگر چیزی اینجا غلط است، جای اصلاحش docblock همان متد
> کنترلر است، نه این فایل.

**پایه:** `http://127.0.0.1:8100/api/v1`

## قراردادهای مشترک

| موضوع | قرارداد |
|---|---|
| زبان | هدر `Accept-Language: fa` یا `en`. پیش‌فرض فارسی. |
| احراز هویت | `Authorization: Bearer <token>` — توکن از `/auth/login` |
| مبالغ | همه به **ریال** و عدد صحیح. تبدیل به تومان کار نمایش است. |
| خطای اعتبارسنجی | کد ۴۲۲ با `errors` به تفکیک فیلد |
| سبد مهمان | هدر `X-Session-Id` — بدون آن سبد به کاربر گره نمی‌خورد |

در مجموع **124 اندپوینت** در 16 گروه.
